# Credits and a polite request

thumbpad is released into the public domain (see [LICENSE](LICENSE)). You may do
anything with it, with no conditions.

**A request, not a requirement:** if you use ideas or code from this project, I'd
appreciate a mention, along with the projects it builds on. Giving credit is good
manners in open source, and it helps people find where ideas came from.

## Projects this builds on

- **[Thumb-Key](https://github.com/dessalines/thumb-key)** by Dessalines and contributors
  (AGPL-3.0). It's the model for the swipe-key interaction: tap, 8-way swipes and
  long-press per key, a split "type-split" grid with frequent letters on center taps, and
  modifier layers. The original Czech layout this project grew from was designed and used
  in Thumb-Key. No Thumb-Key source code is included here; only ideas and the author's own
  layout data are reused.
- **[MessagEase](https://www.exideas.com/ME/)** by Saied B. Nesbat / Exideas. It
  invented the 3×3 swipe keyboard, and the portrait one-handed layout is inspired by
  it. MessagEase is a separate, proprietary product. This project isn't affiliated with
  or endorsed by Exideas.
